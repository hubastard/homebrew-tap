# Homebrew tap for Speedrun

[Speedrun](https://github.com/hubastard/speedrun): fast black-box UI tests for Android and
iOS, in plain YAML.

```sh
brew install hubastard/tap/speedrun
```

`brew upgrade speedrun` updates it. macOS on Apple silicon and Linux x86_64.

The formula follows Speedrun's latest release: `update.sh` writes it from the release's
packages and their published SHA-256, run by the `Update speedrun` workflow after each
release and every 6 hours.
